# 开发指南

## 环境准备
| 工具 | 版本 | 来源 |
| --- | --- | --- |
| JDK | 17 或更高 | `pom.xml` 配置 `java.version=17`；本机也曾用 OpenJDK 26 启动 |
| Maven | 本机 PATH 或 IntelliJ 内置 Maven | 项目没有 `mvnw`；可用 IntelliJ bundled Maven |
| Redis | 可选 | 本地未启动时 `ShortTermMemoryService` 会回退到进程内 Map |
| Pinecone | 必需，用于真实入库和检索 | `.env` 中配置 `PINECONE_API_KEY`、`PINECONE_INDEX`、可选 `PINECONE_HOST` |
| DashScope / 阿里百炼 | 必需，用于 embedding 和 chat | `.env` 中配置 `DASH_SCOPE_API_KEY` 或兼容变量 |

## 常用命令
| 操作 | 命令 |
| --- | --- |
| 切换目录 | `cd D:\JavaPrograms\TeamRagKnowledgeBase` |
| 刷新 PowerShell PATH | `$env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')` |
| 本地启动 | `mvn spring-boot:run` |
| 运行测试 | `mvn test` |
| 打包 | `mvn package` |

## 配置文件清单
| 文件 | 作用 |
| --- | --- |
| `.env` | 本地真实密钥和运行参数；不要提交 |

```powershell

  -H "Content-Type: application/json" `
  -d "{\"query\":\"请总结这份资料的关键规范\",\"conversationId\":\"demo\",\"project\":\"team-rag\"}"
```

## 调试与验证
- 修改 Java 代码后运行 `mvn test`。
- 修改静态前端后运行 `mvn process-resources`，再刷新 `http://localhost:8080/`。
- 启动时如果提示 `Port 8080 was already in use`，先查占用进程，再决定是否停止。
- JDK 新版本可能出现 Tomcat JNI native access warning；这是运行时警告，不是业务错误。
- 真实问答需要 `.env` 中 DashScope 和 Pinecone 配置完整，测试命令不会校验真实外部服务可用性。

## 注意事项
- 不要在文档、日志或提交中暴露 `.env` 里的 API Key。
- 修改默认模型时优先改 `.env` 或 `application.properties` 的默认值，再同步 `RagProperties` 默认字段。
- `DocumentForm` 中只有 `file` 是上传必需字段；`docType`、`project`、`tags`、`description` 是可选元数据。
