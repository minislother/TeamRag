# 业务知识

## 项目背景
TeamRagKnowledgeBase 当前业务定位为 baituan 社团资料知识库，用于集中存储和检索社团介绍、社团章程、招新材料、活动指引、预算报销、安全预案、会员管理、复盘报告等资料，服务普通学生、社团成员、社团负责人和平台管理员。

## 领域术语
| 术语 | 代码名 | 业务含义 |
| --- | --- | --- |
| 社团资料知识库 | TeamRagKnowledgeBase | 面向 baituan 社团资料的 RAG 知识库 |
| 文档入库 | document upload | 上传社团介绍、章程、活动指引、招新材料、复盘报告等资料 |
| 短期记忆 | short-term memory | 保存同一会话内的连续追问，用于查询重写和多轮问答 |
| 长期记忆 | long-term memory | 保存可复用的社团资料事实、管理规则或运营经验 |
| 资料类型 | docType | 社团介绍、社团章程、活动指引、招新材料、财务报销、安全预案等 |
| 项目/社团 | project | 通用资料默认使用 baituan，也可按具体社团或项目隔离 |

## 核心业务规则
- 通用社团资料默认 `project=baituan`。
- 单个社团的私有或专项资料可以使用具体社团简称作为 `project`，并通过权限控制隔离。
- 文档版本以 ACTIVE 版本参与检索，旧版本或失败版本不应进入问答 Prompt。
- 知识库无命中时，回答必须标注“社团资料知识库未命中”，避免把通用模型推理误认为已入库资料事实。

## 文档入库规则
- 推荐资料类型：社团介绍、社团章程、活动指引、招新材料、财务报销、安全预案、会员管理、复盘报告、常见问答。
- 文件名应体现主题，例如 `轮滑社社团章程.md`、`社团招新活动指引.md`。
- 标签建议 2 到 5 个，覆盖业务动作和场景，例如招新、报名、审核、场地、预算、安全、复盘。
- 不要上传身份证号、银行卡号、内部账号密码、未脱敏报名名单等敏感信息。

## 问答规则
- 优先基于社团资料知识库内容回答。
- 如果检索片段没有覆盖问题，应明确说明资料库未找到依据。
- 可给出通用建议，但必须标注来源边界，不能编造 baituan 内部规则、社团章程条款或活动审批要求。

## 业务关系图
```text
学生/社团负责人/管理员 -> 上传或提问 -> 社团介绍/章程/活动指引/招新材料 -> 可追溯的 RAG 回答
```
