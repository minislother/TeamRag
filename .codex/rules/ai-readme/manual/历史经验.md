## 踩坑记录

| 问题 | 原因 | 方案 |
| --- | --- | --- |
| PowerShell 提示 `mvn` 无法识别 | Maven 目录没有进入当前 Shell 的 PATH | 刷新 PATH 或使用 IntelliJ 内置 `mvn.cmd` |
| 启动提示 8080 被占用 | 已有 Spring Boot 或其他进程占用端口 | 用 `Get-NetTCPConnection -LocalPort 8080` 查 PID，再按需停止 |
| JDK 输出 native access warning | 新版 JDK 对 Tomcat JNI native load 的限制提示 | 当前是警告，不等同于启动失败；未来可按 JDK 要求配置 native access |
