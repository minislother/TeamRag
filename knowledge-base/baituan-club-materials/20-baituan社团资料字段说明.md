# baituan 社团资料字段说明

资料类型：字段说明  
项目：baituan  
标签：字段、元数据、检索  

## docType

docType 表示资料类型，建议使用稳定枚举，例如社团介绍、社团章程、活动指引、招新材料、财务报销、安全预案、复盘报告、常见问答。稳定的 docType 有助于筛选和统计。

## project

project 表示资料所属项目或社团范围。通用资料填写 baituan；单个社团资料可以填写社团简称，例如 skating-club、music-club。需要统一管理时，也可以用 baituan 作为项目，再用 tags 标记具体社团。

## tags

tags 用于补充检索关键词，建议 2 到 5 个。标签应覆盖业务动作和场景，例如招新、报名、审核、场地、预算、安全、复盘、换届。不要把整段描述写进 tags。

## description

description 用于说明资料用途，例如“社团负责人发起活动前查看”“普通用户报名活动前查看”。清晰的说明有助于管理员维护资料。

## 文件命名

建议使用“序号-资料主题.md”或“社团名称-资料类型-版本.md”。文件名应能独立表达主题，避免使用“最终版”“新文档”“资料1”等模糊名称。
